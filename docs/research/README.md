# Research — NCR

Папка `/docs/research/` — исследовательские материалы проекта **Neural CAD Reconstruction**.

## Статусы

- `план` — только заголовок и вопросы к изучению;
- `в работе` — материал активно исследуется и дополняется;
- `готово` — материал проверен и пригоден для дальнейшего использования.

## Файлы

| Файл | Тема | Статус |
|---|---|---|
| [`00_terminology.md`](00_terminology.md) | Определения терминов, используемых в исследовании | в работе |
| [`01_sources.md`](01_sources.md) | Научные источники, аннотации | в работе |
| [`02_problem.md`](02_problem.md) | Актуальность, объект, предмет, цель и задачи | в работе |
| [`03_approaches.md`](03_approaches.md) | Первичный анализ нейросетевых подходов | в работе |
| [`04_metrics.md`](04_metrics.md) | Метрики качества, корректности CAD и распознавания | в работе |

## Правила ведения

- Определения используемых терминов хранить в `00_terminology.md`.
- Источники информации заносить в `01_sources.md` по указанным там правилам и ссылаться на них через постоянные идентификаторы `[S#]`.
