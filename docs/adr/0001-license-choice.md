# ADR-0001: Выбор лицензии для проекта

## Status

Accepted

## Context

Проект представляет собой pet-проект и основу выпускной квалификационной работы. Цели лицензирования: (1) позволить использовать и развивать подходы, в том числе в коммерческих продуктах; (2) не допустить сценария, при котором организация берёт код, модифицирует его и продаёт без раскрытия изменений; (3) при этом не требовать от компаний раскрывать весь их проприетарный или чувствительный код, который лишь взаимодействует с нашим.

## Decision

Выбрана **Mozilla Public License 2.0 (MPL-2.0)**. MPL-2.0 защищает исходный код от закрытия. Альтернативы (MIT, Apache 2.0, GPL, LGPL) отклонены: MIT и Apache разрешают закрытые модификации; GPL требует раскрытия всего производного продукта; LGPL ориентирована на библиотеки и создаёт сложности с перелинковкой для приложения.

## Consequences

**Плюсы:** 

- модификации нашего кода возвращаются сообществу;
- коммерческое использование возможно; 
- компании могут комбинировать наш код со своим закрытым кодом на уровне отдельных файлов. 

**Осознанное ограничение:**

MPL-2.0 защищает файлы с исходным кодом, но не веса моделей. Компания может до обучить нашу модель и не раскрывать полученные веса, так как они не являются «Source Code Form» в понимании лицензии. Это принимается как компромисс: главная ценность — методы и код, а не конкретные веса.
