# Обзор существующих нейросетевых подходов

## 1. Предмет сравнения

Рассматриваются подходы, в которых **2D-чертёж является входными данными**, **нейронная сеть участвует в восстановлении**, а результатом служит **3D CAD-модель**. Обычная генерация изображения 3D-объекта, облака точек или полигональной сетки сама по себе не решает поставленную задачу. Такие представления могут использоваться как промежуточные, если предусмотрено получение CAD-модели.

Сравнение необходимо проводить на трёх независимых уровнях:

1. **Вход:** растр или векторные элементы, число и согласованность проекций, наличие размеров и аннотаций.
2. **Роль нейросети:** генерация модели или последовательности построения, выбор операций, распознавание элементов чертежа либо комбинация этих действий.
3. **Получение CAD-модели:** выполнение конструктивных операций, построение твердотельной геометрии посредством CAD-системы или формирование иного пригодного для CAD геометрического представления.

Не следует противопоставлять CAD-код, последовательность операций, CSG и B-Rep как взаимоисключающие варианты. Например, последовательность операций может задаваться кодом, использовать CSG и при выполнении создавать B-Rep-тело. Отдельно следует оценивать наличие или отсутствие параметрической истории: она не следует автоматически из названия «CAD-модель» [S1].

## 2. Нейросетевые подходы

### 2.1. PlankAssembly (2023) [S2]

**Вход:** линейные чертежи с тремя ортогональными видами.

**Нейросетевой подход:** Transformer, генерирующий последовательность описаний формы (*shape programs*).

**Получение результата:** выполнение предсказанной программы для реконструкции 3D CAD-модели.

**Что показывает работа:** моделирование соответствий между видами через обучаемую генерацию последовательности может быть устойчивее к ошибкам и неполноте чертежей, чем методы с жёстко заданными соответствиями. **Ограничение переноса:** представление shape programs разработано для исследуемого авторами класса объектов; пригодность для произвольных деталей не доказана этой публикацией.

### 2.2. CAD2Program (2025) [S3]

**Вход:** 2D CAD-чертёж, представленный в виде растрового изображения.

**Нейросетевой подход:** Vision-Language Model; визуальное кодирование с помощью ViT и авторегрессионная генерация текстового описания параметрической 3D-модели.

**Получение результата:** интерпретация полученного текстового представления для построения параметрической модели.

**Что показывает работа:** можно получать пригодное для CAD текстовое представление непосредственно из растра, без обязательного исходного векторного чертежа. **Ограничение переноса:** эксперименты проведены на моделях шкафов; результаты не следует без проверки распространять на произвольные детали.

### 2.3. Reinforcement learning-based parametric CAD reconstruction (2025) [S4]

**Вход:** ортогональные проекции, из которых предварительно извлекают вершины и рёбра; формируется представление *loop-path*.

**Нейросетевой подход:** агент на основе DQN выбирает последовательность пар «контур — траектория» для построения.

**Получение результата:** выбранные действия преобразуются в редактируемую параметрическую CAD-модель; в экспериментах используется FreeCAD.

**Что показывает работа:** нейронная сеть может не порождать всю геометрию напрямую, а обучаться выбирать конструктивные действия из подготовленных кандидатов. **Ограничения:** необходима геометрическая предобработка; опубликованные эксперименты охватывают модели, создаваемые операциями sketch-extrude, а не весь возможный набор CAD-операций; размеры и допуски в рассматриваемых чертежах отсутствуют.

### 2.4. Deep Learning-Based Automation for Converting 2D Engineering Drawings into 3D Solid Models (2026) [S5]

**Вход:** технические чертежи с несколькими видами, геометрическими и размерными обозначениями.

**Нейросетевой подход:** несколько моделей YOLOv4 обнаруживают виды, элементы контура и размерные данные; последующая логика связывает распознанные сведения.

**Получение результата:** построение 3D-твердотельной модели посредством Siemens NX / NX Open.

**Что показывает работа:** нейросеть необязательно должна генерировать CAD-операции целиком; её задача может состоять в извлечении информации для последующего алгоритмического построения. **Ограничения:** публикация исследует ограниченные геометрические элементы (в частности, прямоугольные и круглые выдавливаемые профили, не более двух элементов), поэтому высокие показатели распознавания отдельных объектов нельзя трактовать как универсальную точность реконструкции произвольных деталей.

### 2.5. Automatic Reverse Engineering of Parametric CAD Models from Multi-View 2D Projections Using Deep Learning (2026) [S6]

**Вход:** шесть ортогональных 2D-проекций.

**Нейросетевой подход:** Multi-View CNN (MVCNN) совместно с Transformer для предсказания процедурной последовательности CAD-построения.

**Получение результата:** предсказанная последовательность объединяется с результатами отдельного измерительного модуля и исполняется в Siemens NX.

**Что показывает работа:** возможность комбинировать обучение по нескольким проекциям с явным CAD-построением. **Ограничение сопоставимости:** шесть видов и дополнительный этап измерения отличаются от постановок с одним изображением чертежа или тремя видами; их результаты нельзя сравнивать напрямую без унификации условий.

## 3. Сравнение подходов

| Работа | Вход | Что делает нейросеть | Получение CAD | Основное ограничение для переноса |
|---|---|---|---|---|
| PlankAssembly [S2] | 3 ортогональных вида | Генерирует shape program | Исполнение программы | Специализированный класс объектов |
| CAD2Program [S3] | Растровый 2D-чертёж | Генерирует текстовое параметрическое описание | Интерпретация описания | Эксперименты на шкафах |
| Zhang et al., RL [S4] | Извлечённые геометрические элементы проекций | Выбирает операции из кандидатов | Выполнение CAD-операций | Зависимость от предобработки и sketch-extrude |
| Jong et al. [S5] | Чертёж с размерами | Распознаёт виды, контуры, размерные обозначения | NX Open на основе извлечённых данных | Узкий набор геометрических элементов |
| Ravichandran, Inkermann [S6] | 6 проекций | Генерирует процедурную последовательность | Siemens NX и измерительный модуль | Специфический набор видов и дополнительный модуль |
