# Терминология

## Данные

| Термин | Определение |
|---|---|
| **2D-чертёж (технический чертёж)** | Двумерное инженерное представление объекта, содержащее его проекции, контуры и при необходимости размеры, условные обозначения и другие сведения о форме и конструкции. |
| **Ортогональная проекция** | Изображение объекта на плоскости, полученное параллельным проецированием по направлению, перпендикулярному этой плоскости, без перспективного сокращения размеров вдоль плоскости проекции. |
| **Multi-view (несколько видов)** | Использование двух или более проекций одного объекта с известной либо определяемой взаимной ориентацией для восстановления его пространственной геометрии. |
| **Растровое изображение** | Представление чертежа сеткой пикселей с дискретными цветовыми или яркостными значениями, не сохраняющее само по себе явную структуру линий и дуг. |
| **Векторное представление** | Описание чертежа геометрическими примитивами — отрезками, дугами, окружностями и другими объектами — с численными координатами и параметрами. |
| **Размерная аннотация** | Обозначение на чертеже, задающее геометрический размер или отношение (например, длину, диаметр, радиус, угол) и обычно включающее числовое значение, размерную линию или выноску. |

## 3D-геометрия и CAD

| Термин | Определение |
|---|---|
| **3D-модель** | Цифровое представление пространственной формы объекта, заданное, например, поверхностями, полигонами, объёмными элементами или геометрическими примитивами; само по себе не определяет точность, параметризацию или пригодность для инженерного CAD-моделирования. |
| **3D-реконструкция** | Восстановление пространственной формы или модели объекта на основании неполных либо низкоразмерных наблюдений, в данном случае — 2D-чертежей. |
| **CAD (Computer-Aided Design)** | Автоматизированное проектирование с использованием программных средств для создания, изменения и исследования инженерных моделей. |
| **3D CAD-модель** | Цифровая трёхмерная инженерная модель, содержащая геометрическое представление объекта, пригодное для обработки средствами CAD; может содержать дополнительные параметры и историю построения, но их наличие не обязательно для всех типов моделей. |
| **Твердотельная модель** | Трёхмерное представление объекта с определённой внутренней областью и границей, допускающее объёмные геометрические операции и проверку принадлежности точек телу. |
| **B-Rep (Boundary Representation)** | Представление трёхмерного тела через геометрию его граничных поверхностей, рёбер и вершин и через топологические связи между ними. Само по себе не задаёт историю конструктивных операций. |
| **CSG (Constructive Solid Geometry)** | Способ описания твёрдого тела как композиции геометрических примитивов и операций объединения, пересечения и вычитания; выражается деревом построения или аналогичной структурой. |
| **Mesh (полигональная сетка)** | Приближённое описание поверхности набором вершин и полигональных граней; без дополнительной структуры не хранит параметрическую историю CAD-операций и не эквивалентно полноценной CAD-модели. |
| **Параметрическая CAD-модель** | Модель, в которой форма определяется изменяемыми численными параметрами, геометрическими ограничениями и/или последовательностью конструктивных операций, так что их изменение может перестраивать модель. |
| **История построения** | Сохранённая упорядоченная последовательность операций моделирования и их зависимостей, позволяющая воспроизвести или редактировать конструкцию; восстановленная история не обязана совпадать с действиями исходного конструктора. |
| **CAD-команда / конструктивная операция** | Формализованное действие над моделью или её элементами, например создание эскиза, выдавливание, вырез либо скругление, с необходимыми параметрами. |
| **CAD-код** | Исполняемый программный текст, содержащий вызовы операций построения или CAD API для формирования модели; это возможный способ задания процесса построения, а не обязательный формат результата. |
| **CAD-ядро** | Геометрический программный компонент CAD-системы, выполняющий создание и преобразование тел и проверяющий геометрическую и топологическую корректность результатов. |
| **CAD-валидность** | Выполнение заранее заданных требований к корректности CAD-объекта, например допустимость твёрдого тела для конкретного геометрического ядра, непротиворечивость границ и отсутствие запрещённых самопересечений. |
| **Топология модели** | Структура взаимной связности её вершин, рёбер и граней, отличная от численных параметров их положения и формы. |
| **Sketch (эскиз)** | Двумерное геометрическое построение в плоскости, содержащее линии, дуги, замкнутые профили и при необходимости ограничения, используемое как основа 3D-операций. |
| **Extrude / Sketch-extrude (выдавливание)** | Построение трёхмерной геометрии перемещением плоского профиля вдоль заданного направления на заданное расстояние. |

## Нейросетевые методы и архитектуры

| Термин | Определение |
|---|---|
| **Neural network (нейронная сеть)** | Обучаемая математическая модель из взаимосвязанных вычислительных слоёв, параметры которой настраиваются по данным для аппроксимации зависимости между входом и требуемым выходом. |
| **Deep Learning** | Подход к машинному обучению, использующий многослойные нейронные сети для извлечения признаков и моделирования сложных зависимостей. |
| **CNN (Convolutional Neural Network)** | Нейросеть, применяющая свёрточные фильтры для извлечения локальных пространственных признаков, в том числе из изображений. |
| **MVCNN (Multi-View Convolutional Neural Network)** | Архитектура обработки нескольких изображений одного объекта, объединяющая признаки разных видов, чтобы использовать их совместно при предсказании. |
| **Transformer** | Нейросетевая архитектура, использующая механизм внимания для обработки взаимосвязей между элементами входной или выходной последовательности. |
| **ViT (Vision Transformer)** | Вариант Transformer для изображений, обрабатывающий их как последовательность визуальных фрагментов или токенов. |
| **Vision-Language Model (VLM)** | Модель, связывающая визуальные данные с текстовым представлением и способная, в частности, формировать текст на основании изображения. |
| **Авторегрессионная генерация** | Последовательное предсказание элементов выходного описания, при котором каждый следующий элемент вычисляется с учётом ранее сгенерированных. |
| **YOLO (You Only Look Once)** | Семейство нейросетевых моделей для обнаружения объектов на изображении, предсказывающих их классы и пространственное положение за один проход модели. |
| **Reinforcement Learning (обучение с подкреплением)** | Обучение агента выбирать действия в среде так, чтобы максимизировать ожидаемую суммарную награду по сигналу обратной связи. |
| **DQN (Deep Q-Network)** | Метод обучения с подкреплением, в котором нейронная сеть оценивает ожидаемую суммарную награду для пар «состояние — действие», позволяя выбирать действия на её основе. |
| **Loop-path** | Представление кандидата CAD-построения через контур (loop) и траекторию (path) с параметрами, используемое для выбора последовательности операций в работе Zhang et al. [S4]. |
| **Shape program** | Формальное описание пространственной формы набором параметризованных конструктивных инструкций, выполнение которых позволяет получить 3D-геометрию; набор команд зависит от конкретного исследования. |

## Экспериментальные понятия

| Термин | Определение |
|---|---|
| **Baseline (базовое решение)** | Контрольный метод, результаты которого используются для оценки преимуществ и недостатков исследуемого подхода при сопоставимых условиях эксперимента. |
| **Ground truth (эталон)** | Эталонные данные, описывающие правильный результат для исследуемого объекта и используемые при обучении или оценке модели. В зависимости от задачи могут включать геометрию, параметры, классы объектов или другую разметку. |
| **TP (True Positive)** | Истинно положительный результат: объект или элемент, который действительно относится к положительному классу и правильно определён моделью как положительный. |
| **FP (False Positive)** | Ложноположительный результат: объект или элемент, который не относится к положительному классу, но ошибочно определён моделью как положительный. |
| **FN (False Negative)** | Ложноотрицательный результат: объект или элемент, который относится к положительному классу, но ошибочно определён моделью как отрицательный. |

## Метрики качества

| Термин | Определение |
|---|---|
| **3D IoU (Intersection over Union)** | Метрика пространственного совпадения двух объёмных тел, показывающая, какую долю их общего объёма объединения занимает пересекающаяся часть. Чем выше значение, тем больше геометрическое совпадение. |
| **Chamfer Distance (CD)** | Метрика геометрического расхождения двух наборов точек, учитывающая расстояния от точек каждого набора до ближайших точек другого. Меньшие значения означают более близкое расположение точек; результат зависит от выбранного варианта вычисления. |
| **Hausdorff Distance (HD)** | Метрика геометрического расхождения двух множеств точек, определяемая наибольшим расстоянием от точки одного множества до ближайшей точки другого с учётом обоих направлений. Характеризует максимальное отклонение и чувствительна к выбросам. |
| **MAE (Mean Absolute Error)** | Метрика средней абсолютной ошибки численных предсказаний относительно эталонных значений. Показывает среднюю величину отклонения без учёта его знака и измеряется в единицах исходной величины. |
| **Precision** | Метрика классификации или обнаружения объектов, показывающая долю правильных положительных предсказаний среди всех положительных предсказаний модели. |
| **Recall** | Метрика классификации или обнаружения объектов, показывающая долю правильно обнаруженных положительных объектов среди всех действительно положительных объектов. |
| **F1-score** | Метрика классификации или обнаружения объектов, объединяющая Precision и Recall посредством гармонического среднего и позволяющая оценивать их баланс одним числом. |
| **Execution success rate** | Доля сгенерированных программ или последовательностей операций, выполнение которых успешно завершается в заданной среде исполнения по установленным критериям. |
| **CAD validity rate** | Доля созданных CAD-моделей, удовлетворяющих установленным требованиям геометрической и топологической корректности в выбранной CAD-системе. |
