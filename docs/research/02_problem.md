# Постановка задачи

**Тема:** Создание 3D CAD-моделей на основе 2D-чертежей с использованием нейронных сетей.

## Актуальность

Двумерные технические чертежи широко используются для представления геометрии и конструктивных особенностей изделий. При этом для дальнейшего проектирования, изменения конструкции и выполнения инженерных расчётов часто необходимы трёхмерные CAD-модели.

Создание таких моделей по существующим чертежам обычно требует ручной интерпретации проекций, определения пространственной формы объекта и воспроизведения его геометрии в CAD-системе. Этот процесс может быть трудоёмким, особенно при обработке большого количества чертежей.

Применение нейронных сетей открывает возможности для автоматизации интерпретации графической информации и восстановления трёхмерной геометрии. Однако создание CAD-модели требует не только определения пространственной формы объекта, но и получения геометрического представления, пригодного для дальнейшего инженерного использования.

Таким образом, исследование нейросетевых подходов к автоматизированному созданию 3D CAD-моделей по 2D-чертежам представляет практический интерес для цифровизации технической документации и сокращения трудозатрат на восстановление инженерных моделей.

## Объект исследования

Процесс автоматизированного создания трёхмерных CAD-моделей по двумерным техническим чертежам.

## Предмет исследования

Нейросетевые методы и алгоритмы автоматизированного создания трёхмерных CAD-моделей по двумерным техническим чертежам.

## Цель

Разработать и экспериментально оценить нейросетевой подход к автоматизированному созданию трёхмерных CAD-моделей на основе двумерных технических чертежей.

## Задачи

1. Изучить состав и особенности информации в 2D-чертежах, существенной для восстановления трёхмерной геометрии.
2. Проанализировать существующие нейросетевые подходы к созданию 3D CAD-моделей по 2D-чертежам, сравнить их входные данные, роль нейросети, способ получения CAD-модели, ограничения и доступность реализации.
3. На основании сравнительного анализа обосновать выбор способа создания CAD-модели и нейросетевой архитектуры.
4. Определить требования к данным, выбрать и подготовить набор данных и методику оценки выбранного подхода.
5. Разработать и реализовать решение для создания 3D CAD-моделей по 2D-чертежам с использованием нейронной сети.
6. Провести эксперименты, оценить качество полученных решений, сравнить результаты и проанализировать выявленные ограничения.
